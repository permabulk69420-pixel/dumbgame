# Wood Footsteps

Place the seven game-ready footstep WAV files in this folder using these exact names:

- `wood_step_01.wav`
- `wood_step_02.wav`
- `wood_step_03.wav`
- `wood_step_04.wav`
- `wood_step_05.wav`
- `wood_step_06.wav`
- `wood_step_07.wav`

Expected format: mono PCM WAV, 44.1 kHz, 16-bit.

These files will be used by the distance-based apartment footstep system with small random pitch and volume variation.
